# 個人開平倉規則（適配你的打法）

適用：現股當沖／短打、微型台指（MTX）1 口刮價差。  
本金假設：**300 萬**。目標：每筆進出都有依據，不是感覺。

---

## 0. 共用原則（股票＋期貨）

1. **先寫計畫再下單**：方向、進場價、停損、停利、最多持有時間。沒寫完＝不下單。  
2. **一筆一停損**：進場同時掛停損；虧損中**禁止連續改單往有利自己的方向拖**。  
3. **今日收工條件**（擇一即停）：
   - 連虧 **2** 筆；或  
   - 當日淨損達本金 **0.3%**（約 **9,000**，含股票＋期貨）；或  
   - 期貨已做滿計畫筆數（見下）。  
4. **放大部位**：只在「連續兩週扣成本後為正」後，用固定％風險加碼；不是勝率高就加口／加張。

## 1. 微型台指（MTX）規則 —— 對應你今早的問題

**商品假設**：約 **10 元／點**；每來回成本約 **4 點（≈42 元）**。

### 1.1 開倉（進場）必須同時滿足

| 條件 | 規則 |
|------|------|
| A. 時段 | 只做 **09:05–10:30** 或 **13:00–13:25**；開盤前 5 分、尾盤亂行情不做 |
| B. 方向 | 開盤 10 分定 **偏多或偏空**（看開高低、是否站上／跌破前 15 分高低）。**當日主方向只做一邊** |
| C. 觸發 | 主方向下的「回檔／反彈」進場，不做追價第 3 段；破結構才反向（見下） |
| D. 口數 | 固定 **1 口** |
| E. 上限 | 上午最多 **3** 筆計畫單；達標或觸發收工就停 |

**偏多觸發（例）**  
- 價格回檔不破開盤後低點／前波低，出現止跌（例如連兩根較短K或回測均價不破）→ 限價偏多進場。  

**偏空觸發（例）**  
- 僅當價格**明確跌破**上午結構低點且反抽不過 → 才准空手翻空。  
- **禁止**：剛做完多單小賺，立刻空手翻空（你 10:03 那筆）。

### 1.2 平倉（出場）固定三選一，進場就選好

| 類型 | 點數（MTX） | 金額約 | 說明 |
|------|-------------|--------|------|
| **硬停損** | **−25～−30 點** | −250～−300 | 到價市價／觸價；不可改寬 |
| **停利 A** | **+25～+30 點** | +250～+300 | 達標全出（覆蓋成本後有肉） |
| **時間停** | 持有 **≤ 5 分** | — | 未到停利也未停損 → 市價平，避免拖單 |

**加碼規則（選擇性）**  
- 到 +25 可出一半，剩餘停損移到成本附近；**不移到讓虧損變更大**。  

**禁止**  
- 贏 +11／+16 就跑、虧 −50 才砍。  
- 虧損時把賣單一路往下改（你 10:16→10:23 模式）。

### 1.3 今早若照規則會怎樣（對照）

| 實際 | 規則下應做 |
|------|------------|
| 三筆多單 +41／+16／+11 | 前兩筆可做；第三筆 +11 太薄，應等 +25 或時間停 |
| 10:03 翻空 −54 | **不該做**（剛做多且未破結構） |
| 10:16 多 −75 | 到 −30 必須出，不會拖到 −75 |

## 2. 現股短打規則 —— 對應你的股票帳

### 2.1 開倉

| 條件 | 規則 |
|------|------|
| 燈號 | 綠／黃才新開；**紅燈只減倉或空手當沖極小單** |
| 檔數 | 同時持倉（含當沖未平）**≤ 3 檔** |
| 單筆風險 | 本金 **0.5%～1%**＝**1.5～3 萬**（用停損距離反推張數） |
| 進場 | 要有理由：分點同向 **或** 強勢回測支撐 **或** 當沖價差計畫；沒理由＝試單最多 1 張 |
| 禁止 | 隔夜出清過的標的，**當日不回補隔夜**（可當沖但收盤前必須平） |

**張數公式**

\[
文字{張數} = \frac{文字{單筆風險金額}}{(文字{進場價}-文字{停損價}) × 1000}
\]

例：風險 2 萬、進場 70、停損 68 → 張數 = 20000／(2×1000) = **10 張上限**。

### 2.2 平倉

| 類型 | 規則 |
|------|------|
| 停損 | 進場即定；一般 **−1.5%～−3%**（依股性），觸及就出 |
| 停利 | 至少 **1 : 1.5**（賺的距離 ≥ 停損距離 ×1.5）；當沖薄價差至少要蓋手續費稅 |
| 時間 | 當沖單若 30～60 分無進展 → 減半或全出 |
| 收盤 | 黃燈隔夜市值 **≤ 30～45 萬**；紅燈 **≤ 15 萬或 0**；單檔 **≤ 30 萬** |

### 2.3 隔夜（你最容易破功的地方）

收盤前 15 分強制算：

\[
文字{隔夜市值} = Σ(張數 × 收盤價 × 1000)
\]

超過上限 → **先砍到符合再下班**。  
階梯遠方賣單**不算**已風控。
